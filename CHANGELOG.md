# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [0.2.0] - 2026-11-07

### Added
- **Free `edge` engine** (Microsoft Edge neural voices via `edge-tts`, extra `[edge]`): no account or
  key; it is the default engine when `MIRAGEA_API_KEY` is not set. Sentence boundaries reported by the
  engine are used for subtitle timing; network errors are retried; clear message for unusable
  proxy URLs (`VOICEOVER_EDGE_PROXY`).
- **`openai` engine** (`OPENAI_API_KEY`, standard library HTTP, `tags` become a speaking-style instruction).
- **Automatic voices per speaker**: without a voices file every speaker gets its own voice, chosen from the
  script's language (edge, openai, dummy) or from the actors saved in the Miragea account.
- **New video renderer** built on a single ffmpeg graph: Ken Burns zoom/pan with easing, cross-fades
  (`--transition`), progress bar, title card from the script's first heading, gradient background when no
  images are given, `--fit contain` with a blurred backdrop.
- **Caption styles** (`--style clean|box|bold|minimal`), `--speaker-labels`, `--font`; caption size and
  line length adapt to landscape and vertical video; CJK-aware.
- **`voiceover doctor`** (`--online`, `--json`): checks Python, ffmpeg filters (libass, xfade), engines,
  API keys (never shown), default engine and CJK fonts, with a fix for each problem.
- `voiceover voices --filter TEXT`; `voiceover say` without `--voice` picks a voice from the text's language.
- Real demo media in `docs/assets/` (GIF, MP4, MP3, SRT, vertical Chinese Short) and redrawn example
  slides generated by `examples/make_slides.py`.

### Changed
- Default engine is resolved as: `--provider` / `VOICEOVER_PROVIDER`, else `miragea` when
  `MIRAGEA_API_KEY` is set, else `edge`.
- `voiceover video` burns styled captions by default (`--subtitles burn`) and still writes the `.srt`;
  `--images` is optional.
- Video no longer depends on moviepy; the `[video]` extra is kept (empty) for compatibility.
- Subtitle cues never overlap.
- Miragea requests send a browser-compatible User-Agent that still names the tool.

## [0.1.0] - 2026-11-07

### Added
- `voiceover say`: text to speech for a single line, with actor ids or a reference-audio URL (voice cloning).
- `voiceover script`: multi-speaker Markdown/TXT scripts (`[SPEAKER]:` tags, `[pause N]`, per-line
  `tags`/`speed`/`model`/`lang`), speaker → voice mapping via `voices.json` / `voices.yaml`,
  concatenation with configurable gaps, `manifest.json`, and a per-segment cache.
- SRT subtitles from segment timing (default) or provider speech recognition (`--subtitles recognize`).
- `voiceover video`: faceless slideshow video (moviepy) with sidecar or burned-in subtitles,
  landscape or vertical sizes.
- `voiceover voices` (account voice list, pagination) and `voiceover task` (resume/inspect a task).
- Provider interface (`VoiceProvider`) with entry-point discovery; built-in `miragea` provider
  (async tasks, polling, deterministic idempotency keys, retry on retryable errors, clear
  401/403/409/413/429 messages) and offline `dummy` provider.
- Agent skill `skills/ai-voiceover/SKILL.md`, `--json` output and stable exit codes.
- Offline test-suite with mocked HTTP.
